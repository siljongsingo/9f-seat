# 9층 자리 배치표 (d'strict)

웹에서 바로 쓰는 9층 자리 배치표입니다. GitHub Pages로 배포하고, 데이터는 구글 시트에 저장합니다.

- **현재 버전**: 확정된 배치표입니다. 잠겨 있으며, 직접 수정하거나 저장하려면 비밀번호가 필요합니다.
- **수정 버전**: 아래에 계속 추가됩니다. 이름은 `날짜_ver번호`(예: `261109_ver1`)로 자동으로 붙고, 고치면 자동 저장됩니다.
- **현재 버전으로 반영**: 수정 버전을 확정본으로 올립니다(비밀번호 필요).
- **이미지 저장**: 9층 전체 또는 드래그로 고른 영역만 PNG로 저장하거나 클립보드에 복사합니다.

## 구글 시트 연결 (최초 1회)

1. 구글 시트를 새로 만듭니다.
2. [확장 프로그램 → Apps Script]에 `apps-script/Code.gs` 내용을 붙여넣고 저장합니다.
3. [배포 → 새 배포 → 유형: 웹 앱]을 선택합니다. 실행은 **나**, 액세스 권한은 **모든 사용자**로 둡니다.
4. 배포 후 나오는 웹 앱 주소(`https://script.google.com/macros/s/…/exec`)를 `index.html`의 `CONFIG_API`에 넣거나, 페이지의 [⚙ 설정]에 붙여넣습니다.

비밀번호는 `Code.gs`의 `PASSWORD`에서 바꿀 수 있습니다. 시트에 연결하지 않으면 각자 브라우저에만 저장됩니다.

## 파일

- `index.html`: 배포되는 페이지
- `src.html` + `build.py`: 원본 소스 (`python3 build.py [웹앱주소]` → `index.html` 생성)
- `apps-script/Code.gs`: 구글 시트 저장용 스크립트
